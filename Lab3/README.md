В лабораторной 3 работа ведётся в двух проектах.

1. В своём решении **Lab2** откройте [Lab2/test/Properties.hs](../Lab2/test/Properties.hs). Реализуйте свойства для многочленов и метода Ньютона. Для SimpleLang выберите по одному свойству из каждой группы: состояние, выполнение и программа целиком. Добавьте также собственные свойства. Снимайте соответствующий `ignoreTestBecause` по мере готовности. Свойство для метода Хэлли необязательно.
2. В **Lab3** выполните задания 1–5 в [Streams.hs](src/Streams.hs), затем задания в [FunctorsMonads.hs](src/FunctorsMonads.hs) и задание 6 в `Streams.hs`. В задание 4 входит сравнение времени и памяти. Вариант `minMaxBang` и экземпляр `Traversable Stream` необязательны.
3. Пишите примеры Hspec в [test/Spec.hs](test/Spec.hs), а свойства Hedgehog для потоков и комбинаторов — в [test/Properties.hs](test/Properties.hs). В [test/ClassLaws.hs](test/ClassLaws.hs) уже проверяются законы функторов и аппликативных функторов для Maybe и списков. Включите проверки своих экземпляров из задания 3 и дополните их законами монад в задании 4. Замените `pending` своими примерами, реализуйте и включите заготовки свойств и дополните их собственными проверками.

В конце [FunctorsMonads.hs](src/FunctorsMonads.hs) есть необязательное задание на накопление ошибок с помощью `Validation`.

Запустите `stack test` отдельно в каталогах `Lab2` и `Lab3`. Перед сдачей проверьте, что все обязательные примеры и свойства выполняются: Tasty может сообщить об успехе, даже когда часть проверок помечена `PENDING` или `IGNORED`. Для запуска только свойств используйте `stack test --test-arguments="-p Hedgehog"`, для примеров — `stack test --test-arguments="-p Hspec"`.
