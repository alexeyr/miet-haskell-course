# Лабораторная 4. Утилита pick-lines

Напишите программу, которая выбирает строки текста по номерам. Например, пусть в файле `shopping.txt` четыре строки:

```text
milk
eggs
bread
tea
```

После выполнения лабораторной из каталога `Lab4` можно будет запустить:

```console
$ stack run pick-lines -- --lines 1,3-4 --number shopping.txt
1: milk
3: bread
4: tea
$ stack run pick-lines -- --lines 1,3-4 --invert shopping.txt
eggs
```

## 1. Разберите выбор строк

В [Selection.hs](src/Selection.hs) реализуйте `parseSelection` с помощью Megaparsec. Значение аргумента `--lines` задаётся такой грамматикой:

```text
выбор   ::= элемент ("," элемент)*
элемент ::= номер ("-" номер)?
```

Номер состоит из десятичных цифр и должен быть положительным. Границы диапазона включены, левая граница не превосходит правую. Например, `3-3` выбирает одну строку. Пробелы в записи не допускаются. Разберите аргумент целиком: `2-4x` должно давать ошибку, даже если начало удалось разобрать. См. [лекцию 15 о комбинаторах парсеров](../lecture15_parser_combinators.pdf).

## 2. Выберите строки

В том же модуле реализуйте чистую функцию `selectLines`. Нумерация начинается с 1, пустая строка тоже получает номер. Сохраняйте порядок исходного текста, даже если диапазоны перечислены в другом порядке. При пересечении диапазонов выводите строку один раз. Номера за концом текста ничего не выбирают. С флагом `--invert` выбирайте все строки, номера которых не входят ни в один из диапазонов.

## 3. Опишите командную строку

В [CLI.hs](src/CLI.hs) реализуйте парсер `options` с помощью optparse-applicative:

```text
pick-lines --lines SELECTION [--number] [--invert] [FILE]
```

Аргумент `--lines` обязателен. Подключите `parseSelection` через `eitherReader`, чтобы ошибка выбора обнаруживалась до чтения файла. Флаги независимы и по умолчанию выключены. Для `--help` добавьте описание каждого аргумента. В [лекции 12](../lecture12_io.pdf) есть ссылка на документацию optparse-applicative.

## 4. Соедините разбор и ввод-вывод

Точка входа в [Main.hs](app/Main.hs) уже вызывает `run` после разбора аргументов. Реализуйте `run`: прочитайте файл `FILE`, а если имя не задано — стандартный ввод. Примените `selectLines` и выведите каждую выбранную строку на стандартный вывод с переводом строки. При `--number` добавляйте перед текстом исходный номер и разделитель `": "`. Если ничего не выбрано, вывод пуст.

## Проверка

Запускайте `stack test` из каталога `Lab4`. В [Spec.hs](test/Spec.hs) часть примеров уже записана: снимайте `pending` по мере реализации. Для остальных напишите проверки. Аргументы командной строки можно проверять через `execParserPure`, без запуска отдельного процесса.

Добавьте свойство Hedgehog: для небольших положительных `a ≤ b` запись диапазона `a-b` и перечисление всех номеров от `a` до `b` выбирают одни и те же строки. Разберите обе записи и сравните результаты на сгенерированном тексте. В Hspec результат `check` можно проверить через `shouldReturn True`.
