Вам нужно реализовать функции, определённые в файлах в директории `src`. Порядок:
- Poly.hs
- RootFinding.hs — метод Ньютона; метод Хэлли — необязательное задание
- SimpleLang.hs

В `test/Spec.hs` даны только примеры и заготовки тестов. Нужно не только
заполнить заготовки, но и добавить собственные тесты, в том числе для
граничных случаев и ситуаций, когда методы поиска корней не сходятся.
Остальное смотрите в Lab1.

Тесты запускаются командой `stack test`: Tasty объединяет примеры Hspec
из `test/Spec.hs` и свойства Hedgehog из `test/Properties.hs`.
Заготовки свойств пока отключены: их нужно будет реализовать в лабораторной 3.
Добавляйте несколько свойств для одной операции, если они проверяют
разные аспекты её поведения,
а также свойства для операций, которых нет в заготовке, и для комбинаций операций.
Можно запускать группы отдельно: `stack test --test-arguments='-p Hspec'`
или `stack test --test-arguments='-p Hedgehog'`.
